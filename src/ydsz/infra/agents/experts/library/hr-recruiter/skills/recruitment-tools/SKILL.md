## 2. 简历筛选 Rubric 模板

### 4 维度打分表（每项 1-5 分）

| 维度 | 1 分（稀缺） | 3 分（达标） | 5 分（突出） |
|------|-------------|-------------|-------------|
| **学历经验** | 学历明显低于要求，经验 < 50% | 学历/经验符合岗位最低要求 | 学历/经验超要求 1 档以上 |
| **技能匹配** | < 30% 岗位所需技能 | 50%-80% 技能有直接证据 | > 90% 技能有深度实践证据 |
| **动机稳定** | 频繁跳职（< 12 月/份）且成果模糊 | 2-3 年一份工作、有可解释的成长 | 清晰的职业主线 + 内部晋升/扩大 scope |
| **红旗风险** | 多项红旗（见下方） | 无红旗但亮点少 | 无红旗且有显著亮点 |

### 红旗清单

- 频繁跳槽且无法合理解释（< 12 个月/份，连续 3 份以上）
- 技能堆砌（列了 30+ 个技术名词但项目描述模糊）
- 项目成果不可量化（缺少数字、排名、规模）
- 时间线重叠（同一时间段出现在两家全职公司）
- 低级错误（联系方式不通、公司名拼写错误、岗位 JD 照抄）

### 加权公式建议

```
总分 = 学历经验 × 0.25 + 技能匹配 × 0.35 + 动机稳定 × 0.25 + (6 - 红旗) × 0.15

推荐阈值：
  - 推荐面试：总分 ≥ 3.8
  - 待定池：  3.0 ≤ 总分 < 3.8
  - 拒绝：    总分 < 3.0 且红旗 ≥ 3
```

## 3. STAR 行为面试题库

### 领导力（Leadership）

1. **"请分享一次你推动一个 controversia l技术决策的经历。反对意见是什么？你如何达成共识？"**
   - STAR 追问：当时的情境/冲突是什么？你的具体行动？最终结果量化？
   - 评分 1-5：被动执行 → 主动推动 → 跨团队影响 → 组织级改变 → 行业影响力

2. **"描述一次你必须在不授予汇报关系的情况下让其他人完成任务的经历。"**
   - STAR 追问：你用了什么影响力策略？遇到阻力时怎么处理？

3. **"讲一个你主动识别并填补团队能力空白的故事。你怎么发现的？采取了什么行动？"**

4. **"请分享一次你必须在信息不足时做出重大决定的经历。"**
   - STAR 追问：你用了什么框架降低不确定性？事后回顾？

5. **"描述一次你 mentor 他人并使其显著成长的经历。你的方法是什么？如何衡量效果？"**

### 协作（Collaboration）

1. **"请分享一次你与另一团队发生严重分歧的经历。你怎么解决的？"**
   - STAR 追问：对方立场是什么？你做了什么让步？关系结果？

2. **"描述一次跨时区/跨文化合作的挑战。你如何调整沟通方式？"**

3. **"讲一个你推动跨团队流程改进的故事。阻力从何而来？你怎么克服？"**

4. **"请分享一次接受批评/反馈显著改变你工作方式的故事。"**

5. **"描述一次你在资源有限时必须多方协调的经历。最终结果如何？"**

### 问题解决（Problem-Solving）

1. **"请分享一个你解决过的最棘手的技术问题。你的思路是什么？"**
   - STAR 追问：你尝试了多少方法？怎么判断放弃/坚持？

2. **"描述一次你发现并修复了一个被其他人都忽略的问题。"**
   - 评分：日常 bug → 隐藏缺陷 → 系统性根因 → 预防机制设计

3. **"讲一个你必须快速学习新技能以完成项目的故事。学习策略是什么？"**

4. **"请分享一次你从零开始设计一个流程/系统的经历。"**

5. **"描述一次你的方案失败后重新调整的经历。什么让你改变思路？"**

### 冲突处理（Conflict Management）

1. **"请分享一次你与经理在重要决策上意见不一致的经历。"**
   - STAR 追问：你表达反对的方式？最终如何处理分歧？

2. **"描述一次你必须在紧迫截止日期和质量标准之间取舍的故事。"**

3. **"讲一个团队成员表现低于你预期时你怎么处理的经历。"**

4. **"请分享一次你必须在维护关系和坚持原则之间平衡的故事。"**

5. **"描述一次你卷入了职场误解，最终如何澄清和修复关系的经历。"**

- 股权/期权需按最新估值折算，注意流动性折扣

## 5. 候选人体验 NPS 度量模板

### 阶段触点设计

```
阶段 1: 职位触达 → 知道 JD 多久投递？信息是否清晰？
阶段 2: 面试安排 → 响应速度？流程是否透明？
阶段 3: 面试过程 → 面试官准备度？沟通体验？
阶段 4: Offer 阶段 → 薪酬沟通透明度？决策速度？
阶段 5: 入职前 → 准备材料清晰度？团队联络？
```

### cNPS 问卷

```
"向朋友推荐本公司的可能性是多少？（0-10分）"
  0-6: 贬损者（Detractor）
  7-8: 被动者（Passive）
  9-10: 推荐者（Promoter）

cNPS = (推荐者% - 贬损者%) × 100
```

### 追踪指标

| 指标 | 目标值 | 计算方式 |
|------|--------|----------|
| 整体 cNPS | ≥ 40 | (P - D) / 总数 × 100 |
| 各阶段 NPS | ≥ 30 | 按阶段拆分 |
| 投递→面试转化率 | ≥ 25% | 进入面试数 / 投递数 |
| 面试→Offer 转化率 | ≥ 30% | 发 Offer 数 / 面试数 |
| Offer 接受率 | ≥ 80% | 接受数 / 发 Offer 数 |
| 流程平均天数 | ≤ 21 天 | 投递到发 Offer 中位天数 |

### 改进闭环

1. **每周**：面试官反馈汇总（面试官维度 NPS 排名）
2. **每月**：候选人体验月报 + 痛点 Top 3 + Action Plan
3. **每季度**：全漏斗数据分析 + 对标调整（JD/Salary/流程）
