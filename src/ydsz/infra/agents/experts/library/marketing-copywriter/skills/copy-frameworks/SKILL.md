# 文案框架工具箱

## 一、六大框架模板与适用渠道

### AIDA（Attention-Interest-Desire-Action）

| 步骤 | 目标 | 写法要点 |
|------|------|---------|
| Attention | 抓住注意力 | 痛点提问 / 反常识数据 / 强 Hook |
| Interest | 引发兴趣 | 故事/案例/场景代入 |
| Desire | 激发欲望 | 描绘拥有后的改变 |
| Action | 号召行动 | 单一明确 CTA |

**适用渠道**：着陆页首屏、EDM 开场、长推文、信息流广告落地页。

### PAS（Problem-Agitate-Solution）

| 步骤 | 目标 | 写法要点 |
|------|------|---------|
| Problem | 点名痛点 | "你是不是也遇到过……" |
| Agitate | 放大痛苦 | 描述不解决的代价/后果 |
| Solution | 给出方案 | 产品即答案，带信任背书 |

**适用渠道**：小红书种草笔记、朋友圈推广、朋友圈文案、骚扰式短视频。

### FAB（Feature-Advantage-Benefit）

| 步骤 | 目标 | 写法要点 |
|------|------|---------|
| Feature | 产品特征 | "我们用了 X 技术" |
| Advantage | 相对优势 | "比 Y 方案快 3 倍" |
| Benefit | 用户利益 | "你每次省 10 分钟" |

**适用渠道**：产品详情页、卖点卡片、对话式 CTA。

### StoryBrand（SB7 简化）

1. **角色**(Character)：主角=用户，不是品牌。
2. **问题**(Problem)：一个具体的外在/内在/哲学问题。
3. **向导**(Guide)：品牌是向导，带共情+权威。
4. **计划**(Plan)：消除疑虑的简单步骤或保证。
5. **行动**(Call to Action)：直接（买/订）或间接（了解）。
6. **成功**(Success)：描绘美好结局。
7. **失败**(Failure)：描绘不行动的代价。

**适用渠道**：品牌故事长文、About 页、情感类短视频。

### Before-After-Bridge

1. **Before**：你现在的痛点场景。
2. **After**：用了产品后的美好画面。
3. **Bridge**：怎么到达——CTA。

**适用渠道**：朋友圈广告、15-30 秒短视频、弹窗。

### 4Ps（Promise-Picture-Proof-Push）

1. **Promise**：核心承诺（标题）。
2. **Picture**：用画面+数字让人"看到"。
3. **Proof**：数据/评价/案例佐证。
4. **Push**：最后推一把——CTA。

**适用渠道**：信息流广告文案、电商主图文案、邮件标题。

## 二、各渠道字数与写作规范

### 微信推文

- 标题：≤ 64 字符（手机端约显示 22 字），突出利益/悬念。
- 正文：800-2000 字。短句、多分段、加粗关键词。
- 开头 3 行决定打开后是否继续阅读。
- 结尾固定模块：价值回顾 + CTA + 互动引导。
- 配图建议：每 300 字一张图或分隔元素。

### 小红书

- 标题：≤ 20 字（截断风险），含核心关键词 + 情绪钩子。
- 封面文案：大字 4-8 字，副标题 ≤ 15 字。
- 正文：300-800 字，口语化、分段清晰、emoji 适度。
- 话题标签：5-15 个，混合大词 + 长尾词 + 品牌词。
- 互动引导："评论区告诉我"、"收藏下次用"。

### 朋友圈

- 主体：100-200 字，6 行以内（超出折叠）。
- 调性：真实、像从自己嘴里说出来的。
- 禁止：全链接、全 hashtag、官方腔。
- 尾部引导：不直接说"买"，说"感兴趣私聊"。

### EDM（邮件营销）

- Preheader：≤ 90 字符，补充标题信息。
- Subject：≤ 50 字符，个性化可提升打开率。
- 正文：150-500 字。利益前置 + 单一 CTA 按钮。
- CTA 按钮文案：动词开头，"立即领取"/"查看详情"。
- 避免触发垃圾邮件词：免费、限时、点击这里（适度可用）。

### 短视频脚本（15-60 秒）

| 秒段 | 目标 | 写法 |
|------|------|------|
| 0-3 | Hook | 提问/反常识/痛点画面 |
| 3-10 | 内容核心 | 1 个核心信息，口语快节奏 |
| 10-End | CTA | 关注/评论/链接/直播间 |

- 字幕：每帧 ≤ 15 字，关键词加粗/变色。
- BGM：前 3 秒选择与 Hook 情绪匹配的音乐。
- 结尾固定话术："评论区扣 1 领资料"、"主页有链接"。

### 着陆页

- 主标题：≤ 30 字，说清"你是谁 + 做什么 + 为什么选你"。
- 副标题：≤ 60 字，补充具体利益。
- 卖点：3-5 条，每条 ≤ 20 字，图标 + 短语。
- CTA 按钮：动作 + 利益（"免费试用 14 天"），主按钮唯一。
- 信任标识：数据/LOGO 墙/用户证言。

## 三、SEO 元信息模板

### Meta Title 模板（≤ 50 字符）

```
{核心关键词} - {品牌名}
{数字+形容词}+{关键词} | {品牌名}
{疑问/痛点} - {品牌名} 解答
```

**示例**：
- "企业微信 SCRM 系统 - 妙手工作台"
- "10 个提效 50% 的 CRM 技巧 | 妙手"

### Meta Description 模板（≤ 150 字符）

```
{价值主张} + {核心卖点} + {适用人群} + {CTA}
```

**示例**：
- "为中小企业打造的轻量级 SCRM 工具，5 分钟上手、自动化客户跟进、微信生态无缝对接。免费试用 14 天。"

### H1 规则

- 每页唯一，与 Meta Title 呼应但不必完全相同。
- 前置核心关键词。
- 避免纯品牌词。

### 关键词密度

- 正文：1-2%（1000 字中出现 10-20 次主词及变体）。
- 避免堆砌：自然融入标题、首段、小标题、结语。
- 长尾词：部署 3-5 个相关问答型长尾。

### JSON-LD 按需建议

- **产品页**：`Product` + `Offer` + `AggregateRating`。
- **文章页**：`Article` / `BlogPosting`。
- **FAQ**：`FAQPage`。
- **组织**：`Organization` + `sameAs`。

## 四、广告法禁用词清单

### 极限词（绝对禁止）

| 类别 | 禁词 |
|------|------|
| 最 | 最佳、最好、最优、最棒、最强、最新、最全 |
| 第一 | 第一、第一品牌、第一名、No.1、第一部分 |
| 百分比 | 100%、百分之百、0 事故、零风险 |
| 独家 | 独家、独一无二、独家代理、唯一指定 |
| 顶级 | 顶级、顶尖、极致、极品、绝佳 |
| 绝对 | 绝对、绝无仅有、绝对安全、永不 |
| 首家 | 首家、首个、首发、开创者（除非有实据） |

### 医疗/保健品用语（禁止非医疗产品使用）

- 治疗、治愈、疗效、疗程、抗炎、消炎、补肾、活血。
- 无毒副作用、增强免疫力、延年益寿。

### 虚假比较级（需有实据，否则避免）

- 全网最低、性价比之王、销量冠军（除非有第三方数据且标注来源）。
- "比 XX 好 XX 倍"（有可验证数据支持时可用）。

### 国家级/行政区划用语

- 国宴、国礼、国家级、央视推荐、政府专用（除非有官方授权证明）。

### 使用原则

- 极限词"擦边球"（如"超好"、"巨好用"）在平台内容规则下也常被限流，建议规避。
- 数字要有出处："90% 用户反馈满意" → "90% 受访用户反馈满意（样本 N=500，XXXX 调研）"。

## 五、CTA 文案库

### 利益驱动

- "免费试用 14 天"
- "立即领取 8 折券"
- "开户即送 ¥100"
- "首月 9 元起"

### 损失厌恶

- "名额仅剩 XX 个"
- "活动倒计时 X 小时"
- "今天下单赠 XX"
- "前 100 名专享"

### 行动指引

- "点击了解详情" / "了解更多"
- "立即咨询客服" / "扫码加微"
- "加入购物车" / "立即购买"
- "预约演示" / "申请试用"

### 信任驱动

- "已为 1000+ 企业服务"
- "30 天无理由退款"
- "已获 ISO 认证"
- "客户评分 4.8 / 5.0"

### 互动引导（社交媒体）

- "评论区扣 1，我发你资料"
- "点赞收藏，下次用得上"
- "转发给那个需要的人"
- "告诉我你在哪个行业"

### 稀缺 + 利益组合

- "限时免费，仅剩 XX 份"
- "今日下单立减 ¥200"
- "前 50 名注册赠全套模板"
