# 合同条款库 (Contract Clauses Library)

## ⚠️ 重要警示

**本库仅供商务与法律参考，在任何情况下均不构成法律意见。** 合同条款的适用性取决于具体交易背景、管辖法律和当事人意思表示。所有涉及签订、修改、终止合同的重大决策，应咨询持有执业资格的律师。本库资料基于 2025 年中国现行法律法规整理，后续立法修订可能导致部分条款失效。

## 1. 采购合同核心条款清单

### 1.1 货品条款 (Goods / Specification)

- **必备要素**：品名、规格型号、材质/技术参数、数量、单价、总价。
- **风险标记**：「以买方验收合格为准」过于模糊——应补充验收标准（国标/行标/样板确认）。
- **修改建议**：增加「卖方应提供产品合格证、检测报告（CMA 资质机构出具）」兜底条款。

### 1.2 价格条款 (Pricing)

- **必备要素**：固定价/可调价、含税标识、币种、支付方式。
- **风险标记**：价格跟随原材料波动但未设置封顶。
- **修改建议**：增加「调幅超过 ±10% 时，双方应在 5 个工作日内重新协商」上限条款。

### 1.3 交付条款 (Delivery)

- **必备要素**：交付地点（精确到门牌号）、运输方式、风险转移时点（FOB / EXW / DDP）、包装标准。
- **风险标记**：「尽快交付」无拘束力。
- **修改建议**：改为具体日历日 + 逾期违约金（如每日 0.1% 合同总额，累计 ≤ 10%）。

### 1.4 验收条款 (Inspection & Acceptance)

- **必备要素**：验收期限、验收标准、异议提出时限、默认视为合格条款。
- **风险标记**：默认视为合格期限过短（如 24 小时）。
- **修改建议**：一般货物 7-14 天；需安装调试的设备 30 天。

### 1.5 违约责任 (Breach & Liquidated Damages)

- **必备要素**：违约情形列举、违约金/赔偿金计算方式、合同解除权。
- **风险标记**：违约金低于实际损失且无调整机制。
- **修改建议**：约定「违约金不足以弥补损失时，守约方有权要求补足差额」（《民法典》第 585 条）。

### 1.6 知识产权条款 (Intellectual Property)

- **必备要素**：背景知识产权归属、前景知识产权归属、侵权赔偿承诺。
- **风险标记**：买方仅获得「使用权」——需界定「使用」范围（可否再许可/转让？）。
- **修改建议**：明确「买方及其关联公司可永久、全球性、免版税使用」或写明限制。

### 1.7 争议解决 (Dispute Resolution)

- **必备要素**：协商前置期限、管辖法院或仲裁机构、适用法律。
- **风险标记**：约定在对方所在地法院起诉（诉讼成本高）。
- **修改建议**：选择商事仲裁（北国仲/上国仲/深国仲）一审终局，降低异地成本。

## 2. NDA (保密协议) 核心条款

### 2.1 保密范围 (Scope of Confidential Information)

- **常用写法**：以定义条款划定 + 附录列明具体信息清单 + 口头信息需 X 天内书面确认方为保密。
- **风险标记**：「包括但不限于……所有信息」过于宽泛，可能因未明确标识丧失保护。
- **修改建议**：要求披露时以「Confidential」标识口头+有形信息，附件持续更新。

### 2.2 保密期限 (Confidentiality Period)

- **常见区间**：披露后 3-5 年；或直至信息进入公知领域（非因接收方违反）。
- **风险标记**：「永久保密」对被接收方不可执行，法院可能不支持。
- **修改建议**：按信息商业价值分级——核心技术 5 年，一般经营信息 2 年。

### 2.3 返还/销毁条款 (Return or Destruction)

- **常用写法**：收到披露方书面请求后 X 个工作日内返还或销毁，并出书面确认。
- **风险标记**：允许接收方保留备份可能引发后续泄露风险。
- **修改建议**：删除备份保留例外，或明确备份仅限合规存档且仍受保密义务约束。

### 2.4 豁免条款 (Exclusions)

- **标准豁免**：① 披露前已合法持有；② 非因接收方过错进入公有领域；③ 从有权披露的第三方合法取得；④ 独立开发。
- **风险标记**：被接收方主张「独立开发」举证困难。
- **修改建议**：要求接收方保留开发过程记录作为证据。

### 2.5 违约赔偿 (Breach & Remedies)

- **常用写法**：披露方有权寻求禁令救济（injunctive relief）——金钱赔偿不足弥补损失。
- **风险标记**：中国法院对域外 NDA 禁令认可度低。
- **修改建议**：在中国境内 NDA 中明确约定违约金，且选择中国法院/仲裁。

## 3. 劳动合同法定必备条款（《劳动合同法》第 17 条）

### 第 17 条第 1 款所列必备条款

| 序号 | 条款 | 说明 |
|------|------|------|
| (一) | 用人单位名称、住所和法定代表人或者基本信息 | 工商信息应与营业执照一致 |
| (二) | 劳动者姓名、住址和居民身份证或者其他有效身份证件号码 | 核验身份，避免冒名 |
| (三) | 劳动合同期限 | 固定期限 / 无固定期限 / 以完成一定工作任务为期限 |
| (四) | 工作内容和工作地点 | 应精确（避免"全国任意地点"） |
| (五) | 工作时间和休息休假 | 标准工时 / 综合工时 / 不定时（后者需劳动部门审批） |
| (六) | 劳动报酬 | 金额、支付时间、加班费计算基数 |
| (七) | 社会保险 | 五险（养老/医疗/失业/工伤/生育）强制缴纳 |
| (八) | 劳动保护、劳动条件和职业危害防护 | 涉及安全岗位必备 |
| (九) | 法律、法规规定应当纳入劳动合同的其他事项 | 如试用期、竞业限制、保密（可约定属法定补充） |

**风险提示**：欠缺必备条款 → 劳动行政部门责令改正；造成劳动者损害的应承担赔偿责任。

### 3.2 试用期条款禁区

| 合同期限 | 试用期上限 |
|----------|------------|
| 3 个月 ≤ T < 1 年 | ≤ 1 个月 |
| 1 年 ≤ T < 3 年 | ≤ 2 个月 |
| T ≥ 3 年或无固定期限 | ≤ 6 个月 |
| 以完成任务为期限 / T < 3 个月 | 不得约定试用期 |

- 同一用人单位与同一劳动者只能约定一次试用期（《劳动合同法》第 19 条第 2 款）。
- 试用期工资不低于合同约定工资的 80% 且不低于当地最低工资标准。

### 3.3 竞业限制条款（第 23、24 条要点）

- **适用人员**：高级管理人员、高级技术人员和其他负有保密义务的人员。
- **期限**：≤ 2 年。
- **补偿金**：离职后按月支付（未约定 ≥ 离职前 12 个月平均工资的 30% 且不低于当地最低工资）。
- **风险标记**：在职期间预付或工资中包含保密费 = 可能被认定为未支付竞业限制补偿。

## 4. PIPL 数据保护条款模板

依据《个人信息保护法》（PIPL，2021 年 11 月 1 日生效）和配套法规。

### 4.1 告知—同意条款 (Notice & Consent)

```markdown
我们收集、使用您的个人信息前，将通过【弹窗/页面/协议】以显著方式、清晰易懂的语言向您告知：
1. 我们的名称和联系方式；
2. 个人信息的处理目的、处理方式、处理的个人信息种类、保存期限；
3. 您行使本法规定权利的方式和程序。

您通过主动作出肯定性动作（如勾选"同意"按钮）作出同意。我们仅在取得您的同意后开始处理。您有权撤回同意，但不影响撤回前已进行的处理活动效力。
```

**风险提示**：「一揽子同意」违反《个人信息保护法》第 14 条，必须按处理目的分项同意。

### 4.2 跨境传输条款（SCC 标准合同备案版）

```markdown
因业务需要向境外提供个人信息时，我们将：
1. 通过国家网信部门认定的专业机构进行个人信息保护认证，或与境外接收方订立约定双方权利义务的标准合同；
2. 取得您的单独同意（非一揽子同意）；
3. 开展个人信息保护影响评估（PIA）；
4. 向省、自治区、直辖市网信部门备案标准合同。
```

**注意**：《个人信息出境标准合同办法》已施行；需于标准合同生效之日起 10 个工作日内向所在地省级网信部门备案。

### 4.3 数据处理协议 (DPA) 核心条款

- **处理目的与范围**：委托处理的目的、期限、方式、种类、保护措施。
- **协助义务**：响应 Data Subject 权利请求、通知 Data Breach、提供合规审计资料。
- **二次转委托**：未经书面同意不得转委托；转委托后仍承担全责。
- **返还/删除**：合同终止时返还或删除个人信息，并提供书面删除确认。
- **审计权**：委托方有权对受托方数据处理活动进行审计（合理提前通知）。

### 4.4 Data Breach 通知条款

```markdown
发生或可能发生个人信息泄露、篡改、丢失的，我们将：
1. 立即采取补救措施；
2. 通知履行个人信息保护职责的部门（附可能影响 + 已采取措施 + 预防措施 + 联系方式）；
3. 通知个人信息主体（内容同上），但若采取措施能有效避免且已采取则除外；
4. 记录事件并保留至少 3 年。
```

## 5. 常见风险条款红色标记示例

| 条款类型 | 风险标记示例 | 替代修改建议 | 法律依据 |
|----------|-------------|-------------|----------|
| 格式条款 | 卖方有权随时修改协议 | 提前 30 天书面通知 + 用户一异议可退出 | 《民法典》第 496 条 |
| 免责条款 | 平台对用户间交易概不负责 | 保留合理审查义务 + 承诺配合争议解决 | 《民法典》第 506 条（人身伤害/故意重大过失免责条款无效） |
| 管辖 | 任何争议提交北京仲裁（实际在上海） | 明确至具体城市仲裁委员会 | 《仲裁法》 |
| 违约金 | 违约金为合同总额 50% | 控制 ≤ 实际损失的 30% 为原则 | 《民法典》第 585 条 |
| 解约 | 一方可无条件提前 30 天解除 | 区分有因解除与无因解除；无因需补偿 | 《民法典》第 563 条 |
| 保密期 | 永久保密义务 | 区分商业秘密（可永久）与一般信息（3-5 年） | 实践惯例 |
| 试用期 | 试用期 6 个月（合同期 1 年） | ≤ 2 个月 | 《劳动合同法》第 19 条 |

## 6. 审查流程 SOP

### 阶段 1：接收 (Receive)

- ✅ 确认合同类型、交易背景、双方角色（甲方/乙方）。
- ✅ 识别中国法 / 域外法管辖、争议解决方式。
- ⏱ 耗时：15-30 分钟。

### 阶段 2：标记 (Annotate)

- ✅ 逐条扫读，用 🔴（红/风险）、🟡（黄/建议修改）、🟢（绿/合规）三级标记。
- ✅ 对照本库条款清单，确认必备条款是否齐全。
- ⏱ 耗时：30-60 分钟（视合同长度）。

### 阶段 3：风险评级 (Risk Rating)

- ✅ 综合红标数量、影响金额、法律后果三维度打分。
- ✅ 输出「高/中/低」总评级：
  - **高**：存在 S0 风险（如违法竞业限制、违约金过高）。
  - **中**：黄标较多，不影响交易但需谈判。
  - **低**：仅有轻微建议，可接受。

### 阶段 4：替代建议 (Redline)

- ✅ 对红标条款提供 1-2 个替代表述（可选强硬/折中方案）。
- ✅ 标注修改的法律/商业理由供内部决策参考。
- ⏱ 耗时：30-90 分钟。

### 阶段 5：复核 (Review)

- ✅ 交叉复核遗漏事项：签名效力、附件完整性、对等性。
- ✅ 最终输出带批注版合同 + 审查报告。
- ⏱ 耗时：15-30 分钟。
