# 合同条款合规清单

> **时效声明**：本清单基于中国现行法律的一般理解整理，法规可能更新。引用时建议提示用户"截至 YYYY 年标准，请以最新法律法规及执业律师意见为准"。

---

## 一、劳动合同法定必备条款清单（《劳动合同法》第 17 条）

| # | 条款 | 法定要求 | 缺/错后果 |
|----|------|---------|---------|
| 1 | 用人单位名称、住所和法定代表人或主要负责人 | 明确 | 合同中无法识别缔约主体 |
| 2 | 劳动者姓名、住址和身份证或其他有效证件号码 | 明确 | 同上 |
| 3 | 劳动合同期限 | 固定期限 / 无固定期限 / 以完成一定工作任务为期限 | 期限不明确则视为无固定期限 |
| 4 | 工作内容和工作地点 | 岗位 + 地点具体描述 | 不得随意调岗调地点 |
| 5 | 工作时间和休息休假 | 标准工时 / 综合计算工时 / 不定时（需审批） | 超时无加班费 → 违法 |
| 6 | 劳动报酬 | 数额、支付形式、支付周期 | 不得低于当地最低工资 |
| 7 | 社会保险 | 依法参加社保 | 不缴社保 → 劳动者可解除+经济补偿 |
| 8 | 劳动保护、劳动条件和职业危害防护 | 与岗位匹配 | 高危岗位必备，缺失 → 行政处罚 |
| 9 | 法律法规规定应当纳入的其他事项 | 如试用期、培训、保密等 | 非标但常见必备 |

### 试用期规则速查

| 合同期 | 试用期上限 |
|--------|----------|
| 3 个月 ≤ T < 1 年 | ≤ 1 个月 |
| 1 年 ≤ T < 3 年 | ≤ 2 个月 |
| T ≥ 3 年 / 无固定期限 | ≤ 6 个月 |

- 试用期**只能约定一次**（同一用人单位与同一劳动者）。
- 试用期工资 ≥ 本单位同岗位最低档工资 / 约定工资的 **80%**，且 ≥ 当地最低工资。

### 竞业限制补遗

- **仅适用**：高级管理人员、高级技术人员、其他负有保密义务的人员。
- **补偿金**：≥ 劳动合同解除/终止前 12 个月平均工资的 **30%**（且 ≥ 当地最低工资标准）。
- **期限**：≤ 2 年。
- **未支付补偿**：劳动者可请求解除竞业限制约定（最高法劳动争议解释一第 38 条精神）。

## 二、采购合同高风险条款清单

### 高风险（红色标记候选）

| 条款 | 风险点 | 公平对照 |
|------|-------|---------|
| 无限赔偿/赔偿不设上限 | 赔偿金额可能远超合同标的 | 应设上限（如合同金额 X 倍或直接损失为限） |
| 间接损失免责 | 造成的利润损失、商誉损失不赔 | 双方对等排除或共同承担 |
| 单方任意解除权 | 一方可无理由随时解除 | 应限定解除条件 + 提前通知 + 已履行部分处理 |
| 先付款后开票/先发货 | 资金风险高 | 合同约定付款-发货-开票节点清晰，背靠背条款 |

### 中风险（黄色标记候选）

| 条款 | 风险点 | 建议 |
|------|-------|------|
| 验收期限过短 | 来不及仔细验收就被视为合格 | 适当延长验收期 + 书面异议权利 |
| 质量标准不明确 | 争议时无据可依 | 引用国家标准/行业标准 + 量化的技术规格书 |
| 违约责任不对等 | 仅一方承担违约条款 | 对等表述 |
| 单方修改权 | 一方可单方变更合同内容 | 删除或需对方书面同意 |
| 不合理的知识产权归属 | 全部 IP 归采购方 | 背景 IP 归各自所有、前景 IP 按贡献约定 |

### 常规注意（绿色标记候选）

| 条款 | 内容 |
|------|------|
| 不可抗力 | 定义、通知义务、后果分担 |
| 保密 | 范围、期限（合同终止后仍有效）、返还/销毁 |
| 通知 | 送达地址、电子邮件视为送达 |
| 准据法 / 管辖 | 建议选择与一方有实际联系的法院/仲裁 |

## 三、商业秘密/NDA 核心条款清单

### 必备要素

| 条款 | 核心要求 |
|------|---------|
| 保密信息的定义 | 不能过于宽泛（"所有信息" → 应具体+标记） |
| 接收方的义务 | 合理保护措施、仅限必要员工披露、不得反向工程 |
| 保密期限 | 合同期限内 + 终止后 X 年（商业秘密型通常 X ≥ 2-3） |
| 除外信息 | 已公开、接收方已独立掌握、法院强制披露 |
| 返还/销毁义务 | 合同结束时返还或销毁 + 书面证明 |
| 违约责任 | 实际损失 / 违约金 / 禁令（injunction） |
| 不适用保密的信息 | 接收方从第三方合法获取、已公开 |

### 高风险信号

- "接收方永久保密" → 过宽，商业秘密一旦公开即不存在。
- "接收方承担一切泄露损失" → 无限责任，应设上限。
- "披露方不对信息准确性担责" → 可能违反诚实信用。

### 标准条款替代建议

**保密信息定义（推荐）**:
> "本协议所称保密信息，系指披露方在本协议有效期内以书面、口头或电子形式提供给接收方的、明确标注为'保密'或依其性质应被视为保密的非公开信息。保密信息不包括：(a) 披露时已属于公知领域的信息；(b) 接收方在披露前已合法持有并有书面记录的信息；(c) 接收方从有权的第三方合法获取的信息。"

## 四、PIPL 数据共享标准合同条款要点

> 参考《个人信息保护法》第 38-40 条、《数据出境安全评估办法》及网信办发布的《个人信息出境标准合同办法》（2023 年 6 月 1 日施行）。

### 必须包含的要素（针对个人信息出境场景）

| # | 内容 |
|----|------|
| 1 | 个人信息处理者和境外接收方的基本信息（名称、地址、联系人） |
| 2 | 处理目的、用途、方式、种类、敏感程度 |
| 3 | 个人信息的保存地点与期限 |
| 4 | 个人信息和个人权益的保障措施（技术 + 管理） |
| 5 | 境外接收方的所在国家/地区个人信息保护政策和法规 |
| 6 | 个人信息主体的权利（查阅、复制、更正、补充、删除等） |
| 7 | 救济途径与违约责任 |
| 8 | 个人信息主体作为第三方受益人的权利 |
| 9 | 合同解除后的处理方式 |
| 10 | 生效条件、签署方式、份数 |

### 事前义务

- 开展个人信息保护影响评估（PIA）。
- 向个人告知境外接收方的身份、联系方式、处理目的、方式、种类、保存期限、个人行使权利的方式等事项。
- 取得个人的**单独同意**（敏感信息 / 跨境场景）。

### SaaS / B2B 场景提示

- 委托处理 vs 共同处理：若 SaaS 供应商独立决定处理目的和方式，可能被认定为共同处理者 → 连带责任风险。
- 数据处理协议（DPA）中需明确：处理目的、期限、方式、种类、保护措施、转委托规则、数据泄露通知义务。

## 五、合同条款三色标记标准定义

### 标记总则

扫描合同条款时，按以下标准进行风险标记和行动建议。

| 色 | 标记条件 | 行动建议 |
|----|---------|---------|
| 🔴 **红** | ① 违反法律、行政法规的强制性规定；② 可能导致合同部分或全部无效；③ 对一方极度不公平（赔偿不对等/无限责任）；④ 缺失法定必备条款 | **必须改**：具体说明删除或修改方案 |
| 🟡 **黄** | ① 条款表述模糊可能产生争议；② 明显倾向对方（但尚不构成严重不对等）；③ 约定情形较少见，未来可能产生风险；④ 法规灰色地带 | **建议改**：给出优化建议，不改也可接受 |
| 🟢 **绿** | ① 属于行业惯例或标准条款；② 双方权利义务对等；③ 符合法律强制性规定 | **可选改**：仅需简单提示即可 |

### 标记输出格式（每条）

```
[🔴/🟡/🟢] **条款标题**
- 原文摘要："..."
- 风险说明：（为什么标此色）
- 通俗解释：（一句话让用户理解风险）
- 替代/修改建议：（如适用）
```

## 六、常用法律合规参考时效说明

> 以下为引用时常用的时效提示模板，实际引用时根据报告时间更新"XXXX 年"字样。

### 法律更新频率

| 领域 | 更新频率 | 典型法规 |
|------|---------|---------|
| 个人信息/数据保护 | 频繁（1-2 年有细则更新） | PIPL、数据安全法、配套国标与部门规章 |
| 劳动用工 | 中等（各地口径频繁） | 劳动法、劳动合同法、地方仲裁口径 |
| 知识产权 | 中等（判例积累） | 著作权法、专利法、商标法、反不正当竞争法 |
| 合同通则 | 稳定（民法典合同编） | 中华人民共和国民法典（2021 年施行） |
| 公司治理 | 稳定（公司法 2023 修订后过渡） | 中华人民共和国公司法（2024 年 7 月 1 日施行） |
| 广告合规 | 中等（市场监管动态） | 互联网广告管理办法（2023 年 5 月 1 日施行） |

### 时效提示模板

```
> 时效提示：本报告法律依据基于截至 YYYY 年 MM 月的有效法规及一般实践理解。
> 具体仲裁 / 诉讼结果受当地口径、证据情况及后续法规更新影响，
> 请以执业律师的专业意见为准。
```
