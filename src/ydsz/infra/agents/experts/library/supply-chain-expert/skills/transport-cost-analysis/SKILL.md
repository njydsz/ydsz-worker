# 运输成本单位化拆解

把物流总成本拆到可比较、可归因的单位口径，定位成本杠杆。

## 执行步骤

1. **口径对齐**（必做）：确认币种、含税/不含税、计费口径（实重/体积重）、
   时间范围、业务量口径（单量/重量/件数）。缺任一项先问再算。
2. **成本分层**：把成本拆成四层，逐层落到单位：

   | 层 | 包含 | 单位化口径 |
   |----|------|-----------|
   | 干线/运费 | 揽收、干线、转运、派送 | 元/票、元/kg |
   | 仓储操作 | 入库、存储、拣货、打包 | 元/单、元/件·天 |
   | 清关合规 | 关税、清关服务费、商检 | 元/票 |
   | 异常与逆向 | 退件、理赔、超时赔付 | 元/票（占总成本%） |

3. **量价分离**：单位成本 = 总成本 / 业务量；对每层算"价格效应"（单价变化）
   与"结构效应"（货量/重量段/目的地结构变化），指出涨幅来自哪一侧。
4. **基准比较**：同线路历史 / 同网络其他线路 / 报价单三者对比；没有可比基准时
   明确写"无可比基准"，不硬造。
5. **杠杆排序**：按"可节省金额 = (单位成本 - 基准) × 业务量"降序列出
   Top 3~5 杠杆，每个杠杆标注实现条件（谈判/结构调整/路由切换）。

## 输出模板

```
口径：币种/计费口径/时间范围/量口径
单位成本拆解表：分层 × (总额, 单位成本, 占比, 环比)
量价分离：价格效应 X 万元 / 结构效应 Y 万元
Top 杠杆：1) ...（预计节省 Z 万元/月，条件：...）
数据缺口：需要补充的数据项及用途
```

## 纪律

- 没有业务量数据就不算单位成本，只给拆解表并标注缺口；
- 占比必须合计 100%（或解释尾差）；
- 报价比较必须同口径（都是到门价/都是仓到仓价），不同口径先折算再比。
