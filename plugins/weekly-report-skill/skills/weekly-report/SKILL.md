# 周报生成

把素材整理成一页能直接发出去的周报。读者是上级与协作方——写成果与进度，
不写流水账。

## 输出结构（固定顺序）

1. **本周概览** — 2~3 句话总结本周最有价值的产出；
2. **关键进展** — 3~5 条，每条格式：`事项 | 进度（百分比或阶段）| 结果`；
   有量化数据必须带上（耗时、性能、覆盖量等）；
3. **问题与风险** — 阻塞项、依赖他人的事项、需要的支持，逐条写清"卡在哪、
   需要谁、什么时候要"；
4. **下周计划** — 3~5 条，动词开头，与本周进展衔接；
5. **需要协调**（可选） — 仅当有跨团队依赖时列出。

## 整理规则

- 只写素材里有的事实，**不编造进度与数据**；素材未提及的项直接省略；
- 流水记录（"周一开了个会"）要**上提为目的与结果**（"推进 X 方案评审，结论 Y"）；
- 每条进展回答"离目标还有多远"，能写百分比就写百分比；
- 问题不藏：写进周报的问题默认公开透明，但不点名批评个人；
- 全文控制在一屏内，写不下就砍次要事项，不压缩字号式凑字数。

## 交付

先输出 Markdown 周报；若用户要文件，写入
`output/weekly-report-<YYYYWW>.md` 后用 `send_file_to_user` 发送。
