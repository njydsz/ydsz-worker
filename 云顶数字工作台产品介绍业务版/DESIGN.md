# 云顶数字工作台产品介绍（业务版）· DESIGN

## 需求对齐
- 主题：云顶数字工作台产品介绍（业务版）
- 受众：公司老板、业务部门负责人（非技术）
- 目标/场合：内部产品介绍会（30–40 分钟），让业务侧理解价值、愿意试点
- 调性：业务价值导向、务实、可信；不堆技术术语，数字以产品事实为准
- 页数：43 页（封面 1 + 执行摘要 1 + 目录 1 + 章节页 4 + 内容 35 + 结束 1）
- 风格路由：通用（产品介绍）

## 全局视觉约定
- 画布 1280×720；padding 上下左右 60px；内容区 1160×600
- 配色（科技蓝）：主 #2563EB / 辅 #E8EEFB·#D6E4F9·#E2E8F0 / 强调 #F59E0B（≤10%）/ 正文 #1E293B·#475569·#64748B / 暖强调 #FFF7E9·#B45309
- 字体：Microsoft YaHei（唯一字族）
- 字号阶梯：封面主标 66 / 章节大字 180+64 / 巨型数字 72–120 / 页面主标 34 / 卡片小标 20–24 / 正文 18 / 脚注 15–16
- 视觉母题：eyebrow 小字 + 44×4 蓝条 + 主标题 + 1px 贯通细线；结论条浅蓝/浅琥珀横条压底
- 配图策略：全篇结构化 Box + 内联 SVG 自绘，与技术版同品牌视觉语言
- 圆角 8–12px；禁用阴影；一页文字样式组合 ≤ 4 种
